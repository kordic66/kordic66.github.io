BASCOM AVR

Microcontroller programming with BASCOM — a BASIC compiler for AVR chips.

Introduction

BASCOM-AVR is a BASIC compiler for AVR microcontrollers. It is beginner-friendly while supporting low-level peripheral access, making it ideal for radio automation projects.

Programmer used: TAFE — a custom-built programmer. Recommended resource: mcselec.com.
